# MFL Android 1.0.86

## 下拉刷新修复（澎湃 OS 风格）
- **松手会回弹了**：上一版只在 `onPostFling` 收尾，慢慢拉/停住再松手时没有惯性速度，
  这个回调根本不会触发，内容就卡在下拉位置。现在直接监听指针抬起：
  过线 → 刷新；不过线 → 弹簧回弹（带轻微过冲）。
- **不再是假刷新**：空关键词下拉时会真的刷新一次本地状态（广告/账号状态 + 房间缓存）
  并给出提示；有关键词则照旧重搜房间。转圈至少展示 600ms，不会一闪而过。
- 指示器改为澎湃 OS 风格：内容把小球"带出来"（由小到大、由淡到实），
  圆弧随拉动比例变长；刷新时匀速旋转。
