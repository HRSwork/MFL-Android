# MFL Android 1.0.94

## 音乐
- 播放对象支持「全部玩家 / 指定玩家」，默认全部。
- 导入过的曲目自动记住（含文件权限），下次直接选；文件不存在会明确提示并移除。
- 新增歌词：为曲目导入 .lrc，播放时在活动栏显示当前歌词。
- 播放选中改用积分板：`/scoreboard players reset * <榜>` 可离线清理。
- 游戏内提示三个开关：活动栏 / T显（`/title`）/ 聊天栏。
- 清理过程中有玩家退出，不再误报「清理失败」。

## 建筑导入
- 铺地 / 边界 / 清理周围：按 `/fill` 单次上限（32768）自动切分，大建筑真正生效。

## 订阅
- 导入结构开关的订阅判定改为以服务端现算的 `clear_around`/`custom_material` 为准，
  不再依赖登录时缓存的订阅状态。

## 版本
- versionName 1.0.94 / versionCode 95
