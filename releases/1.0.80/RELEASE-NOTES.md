# MFL Android 1.0.80（versionCode 81）

- 构建时间：2026-10-17
- 签名：生产 keystore（与线上一致）
- 适用：Android 8.0+（minSdk 26），arm64-v8a / armeabi-v7a

## 更新内容

### 建筑导入
- **修复导入后方块朝向与原文件不一致**：补齐牌子朝向（`ground_sign_direction`）、
  柱子轴（`pillar_axis`）、珊瑚朝向等状态的旋转；90°/180°/270° 旋转时朝向会跟着转。
- **修复牌子没有字**：新增对 Java 1.20+ `front_text` / `back_text` 文本格式的支持
  （含只填 `filtered_messages` 的存档），多行按 Bedrock 的 `\n` 拼回。

### 进房 / 联机
- **连不上游戏时给出中文原因**：`client outdated` → 「客户端版本过旧，游戏服务器拒绝了登录」；
  超时 / 房间已关闭 / 连接被拒各有明确文案，不再只显示英文原始报错。
- **本地没连上游戏会自动申请退还进房绿宝石**：服务端校验同一房间令牌、5 分钟内、
  只退一次，**且扣费后收到过 world_enter（真进去了）不退**。

### 其它
- 沿用 1.0.79：下载进度条（应用内 + 通知栏）、下载中禁止重复点击、
  先要「安装未知应用」权限再下载（授权回来自动继续，不重下一遍）。
