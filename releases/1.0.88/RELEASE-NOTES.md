# MFL Android 1.0.88

## 下拉刷新（第二次修）
- **可以反复刷新了**：上一版把"刷新完成"绑在 `isRefreshing` 的**变化**上；
  空关键词分支里 `true → false` 是同一帧内写完的，composition 观察不到，
  内部状态卡住 → 进页面只能刷一次。现在改成轮询式完成检测（1.2s 宽限 + 20s 兜底）。
- 空关键词下拉改为异步收尾（至少转 650ms），有关键词仍走真实重搜。

## 头像：QQ 头像
- 服务端在 HRS 下发 QQ 号后，抓取 `q1.qlogo.cn` 头像（640px），以 data URI 存进用户记录；
- 个人页与聊天页优先显示这张头像（自己上传过的仍然优先）；
- 按魔数判断图片类型（qlogo 有时把 PNG 标成 jpeg），限制 512KB。
