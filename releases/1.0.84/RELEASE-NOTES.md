# MFL Android 1.0.84

## 修复
- **社区聊天：自己发的消息头像被挤扁**
  Row 里气泡把宽度吃满，右侧 34dp 的头像只能拿到 0 宽（高度仍是 34）→ 看起来是扁的。
  现在气泡改成 `weight(1f, fill = false)`，固定尺寸的头像先测量，永远保持正圆。

## 新功能
- **联机界面：MIUI 风格下拉刷新**（换掉原来只有 Material 小球的做法）
  - 内容跟着手指走（带阻尼），不是只弹一个小圈；
  - 指示器是环形进度：拉多少、弧多长，拉到位变「松开刷新」；
  - 松手有弹簧回弹动画；刷新时球停在固定高度自己转，结束再弹回去。
