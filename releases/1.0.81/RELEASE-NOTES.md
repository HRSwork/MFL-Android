# MFL Android 1.0.81（versionCode 82）

- 发布日期：2026-10-18
- 适用：Android 8.0+（minSdk 26），arm64-v8a / armeabi-v7a

## 更新内容

### 建筑导入
- **经典 `.schematic` 现在保留方块实体数据**：读取 `TileEntities`，命令方块的命令、牌子文字等内容不再随方块一起丢失。
- **修复旧格式方块朝向/状态不跟随的问题**：经典 `.schematic` 中优先使用 ID + `data` 转换；补齐铁砧方向与损伤、命令方块朝向与条件位、活塞、火把、梯子、中继器/比较器、发射器、箱子、熔炉、漏斗、投掷器等映射。
- **修复铺底/清理/边界开关**：本地与托管导入兼容 `foundation`/`deny`、`clear_around`/`pre_clear` 等字段别名；铺底/清理改在机器人到达建筑区块后执行，边界前回到建筑中心。

### 本地联机
- **修复中继握手收到 UDP `read: message too long`**：RakNet 接收缓冲区扩大到完整 UDP 数据报大小，避免有效报文因缓冲区过小被内核丢弃。
- 连不上游戏时继续显示可读的中文原因；本地连接失败会申请退还进房绿宝石（服务端校验令牌、时限、是否已进入世界及是否重复退款）。
