本仓库只存放 **已编译的 APK** 与对应更新说明；源码与服务端在 [MFL-Tool](https://github.com/HopeRealmStudio/MFL-Tool)。

## 目录约定

```
releases/<版本号>/
  MFL-<版本号>.apk     已签名安装包
  RELEASE-NOTES.md     这个版本改了什么、怎么验
  SHA256SUMS           校验和（下载后请核对）
```

## 安装说明

1. 下载对应版本的 `MFL-<版本>.apk`；
2. 首次安装需要在系统里允许「安装未知应用」（按提示授权一次即可）；
3. 校验：`sha256sum MFL-<版本>.apk` 与 `SHA256SUMS` 一致；
4. 覆盖安装不会清除账号与本地设置。
