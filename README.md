## 安装说明


1. 下载对应版本的 `MFL-<版本>.apk`；
2. 首次安装需要在系统里允许「安装未知应用」（按提示授权一次即可）；
3. 校验：`sha256sum MFL-<版本>.apk` 与 `SHA256SUMS` 一致；
4. 覆盖安装不会清除账号与本地设置。
